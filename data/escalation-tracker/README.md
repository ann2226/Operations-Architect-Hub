# Levrly Escalation Tracker

Daily copy of the [source spreadsheet](https://docs.google.com/spreadsheets/d/1t2rKmmxya7lKrGfd2sLYZsXH7n5TINuC/edit) (an .xlsx file in Drive). The spreadsheet is the source of truth: edit it there, not here. These files are overwritten by the `Sync spreadsheets` GitHub Action every day.

Contains client and team names. Keep this repository private.

No data has been pulled yet. The first sync runs once the repository is private and the `GOOGLE_SERVICE_ACCOUNT_JSON` secret is set (see the main README).
